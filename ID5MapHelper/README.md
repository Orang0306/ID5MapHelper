# 加页手记地图助手（ID5 Map Helper）

> 第五人格「加页手记」玩法的离线安卓地图辅助工具，悬浮窗显示，特征秒级匹配地图。

## ✨ 功能特性

- **🗺️ 地图管理**：添加、编辑、删除地图，支持导入地图平面图
- **🎯 特征匹配**：通过门型、朝向、侧门位置、二楼侧门、楼层等特征，秒级匹配当前地图
- **🪟 悬浮窗模式**：可拖动小球 + 点击展开地图面板，悬浮在游戏上方
- **📖 路线记录**：每张地图可记录房间列表、宝箱数量、跑图路线文字
- **🔍 缩放查看**：地图图片支持双指缩放、拖动查看细节
- **📴 完全离线**：所有数据本地存储，不需要联网
- **🌙 暗色主题**：游戏风格深色界面，不刺眼

## 🚀 快速开始

### 环境要求
- Android Studio Hedgehog (2023.1.1) 或更高版本
- JDK 17
- Android SDK 34
- 最低支持 Android 7.0 (API 24)

### 编译安装

1. **打开项目**
   ```
   用 Android Studio 打开 ID5MapHelper 文件夹
   ```

2. **同步 Gradle**
   - 等待 Gradle 同步完成
   - 如果提示缺少 SDK，点击安装即可

3. **连接手机**
   - 手机开启「开发者选项」→「USB 调试」
   - 用 USB 线连接电脑

4. **运行安装**
   - 点击 Android Studio 顶部的 ▶️ Run 按钮
   - 选择你的手机，等待安装完成

### 首次使用

1. **授予悬浮窗权限**
   - 打开 App → 点击「开启悬浮窗」
   - 系统会跳转到权限设置页，允许「在其他应用上层显示」

2. **添加地图**
   - 点击右下角 ➕ 按钮
   - 填写地图名称（如「左T房」）
   - 选择地图平面图（从相册导入）
   - 设置特征：门型、朝向、侧门、二楼侧门、楼层
   - 填写房间列表、宝箱数量、跑图路线
   - 点击保存

3. **识别地图**
   - 进入游戏后，观察进门的地形特征
   - 点击悬浮小球 → 点击「识别」
   - 选择你观察到的特征 → 开始匹配
   - 匹配结果按相似度排序，点击查看详情

4. **游戏中使用**
   - 开启悬浮窗后切换到第五人格
   - 屏幕边缘会有一个半透明小球
   - 点击小球展开地图面板
   - 面板可拖动，支持上一张/下一张切换
   - 再次点击小球收起面板

## 📋 地图特征说明

| 特征项 | 可选值 | 说明 |
|--------|--------|------|
| 门型 | T型/Y型/十字/L型/方型/三缺一/红门/凹门/其他 | 进门看到的整体形状 |
| 大门朝向 | 上/下/左/右 | 你进门时面对的方向 |
| 侧门位置 | 无/左/右/上/下/左上/右上/左下/右下/左右 | 侧门在入口的哪个方位 |
| 二楼侧门 | 无/有 | 是否有通往二楼的侧门 |
| 楼层 | 一楼/二楼/双层 | 地图主要楼层 |

### 匹配权重
- 门型：40分（最关键）
- 大门朝向：25分
- 侧门位置：20分
- 二楼侧门：10分
- 楼层：5分

> 选得越全，匹配越准。通常门型+朝向就能锁定大部分地图。

## 🔧 技术栈

- **语言**：Kotlin

- **数据库**：Room (SQLite)
- **异步**：Kotlin Coroutines + Flow
- **图片缩放**：PhotoView
- **悬浮窗**：WindowManager + 前台服务

## ⚠️ 注意事项

1. **封号风险**：本工具仅为地图查看辅助，不修改游戏数据、不注入游戏进程，属于正常的悬浮窗应用。但请自行评估使用风险。
2. **悬浮窗权限**：部分手机（小米、华为、OPPO等）需要在系统设置中额外开启「后台弹出界面」「显示悬浮窗」等权限。
3. **游戏检测**：第五人格可能检测到悬浮窗，但本应用不读取游戏画面、不模拟操作，通常不会被判定为外挂。
4. **数据备份**：地图数据存在应用私有目录，卸载 App 会丢失数据，建议重要地图截图备份。

## 🤝 常见问题

**Q: 悬浮窗不显示？**
A: 检查「设置 → 应用 → 地图助手 → 显示在其他应用上层」权限是否开启。小米手机还需开启「后台弹出界面」。

**Q: 悬浮窗在游戏里消失？**
A: 部分手机的省电策略会杀死后台服务，将 App 加入电池优化白名单。

**Q: 匹配不到地图？**
A: 减少筛选条件试试，或检查地图特征是否填写正确。门型是最关键的特征。

**Q: 如何导入大量地图？**
A: 目前只能一张张手动添加。后续可考虑支持 JSON 批量导入。
